## 海外 VPS 比較該先比什麼：線路等級，不是核心數

先比線路，再比配置。同樣標 2 核 4G 的機器，掛在普通 163 骨幹上與走 CN2 精品網，白天差距不明顯，晚上八點到十一點完全是兩種體驗。

多數標榜「中國優化」的海外 VPS，實際只是把這句話印在首頁；晚上的表現仍會回落到擁塞路徑，掉速很明顯。這也是為什麼「晚高峰不掉速」在中文 VPS 圈被當成有效的區分標準。

三個線路代號值得先弄清楚，因為你付的溢價主要買這三樣：

- **CN2（AS4809，中國電信精品網）**：比一般 163 骨幹（AS4134）擁塞更低、抖動更小，電信用戶感受最直接。
- **AS9929（中國聯通精品國際線）**：對聯通用戶是同一套邏輯，晚高峰的穩定度比普通國際出口好。
- **CMIN2（AS58807，中國移動國際網絡 2）**：移動較新的國際出口，用來緩解移動長期存在的國際擁塞。

GoMami 把三者打包成「China Mainland Optimized Pro」，一台機器同時服務三大營運商，而不是某一家被打爆時全部退回飽和路徑。官方標稱中國大陸方向 RTT < 50ms，這個數字來自官方頁面，不是可重現的實測，參考價值有限；真正有價值的是路由本身走得對不對，官網提供 lg.gomami.io 可以自己 traceroute 驗證。

## 條款裡五個容易漏掉的細節

這些內容不在首頁，但會直接影響你用得順不順。

**1. 流量超限有兩套完全不同的規則。** VPS 方案用完月流量後是限速到 20 KB/s，伺服器保持在線、不額外扣費，直到下個計費週期；Forge 獨立伺服器則是超出後按 $0.06/GB 計費。把兩者混為一談會嚴重誤判成本，尤其是跑影片或大流量抓取的 Forge 用戶。

**2. 24 小時退款不是免費試用。** 官方政策是啟用後 24 小時內可申請全額退款，退回原支付方式，但**僅限首次購買、每人一次，續費訂單不適用**。流程是登入後開 Ticket、選 Billing 類別、寫明理由。到帳時間支付寶約 1–3 個工作日，信用卡 5–10 天。把它理解成「先買再決定要不要留」比較準確。

**3. DDoS 防護的口徑有兩套說法。** 官網行銷頁寫的是最高 600 Gbps 清洗能力；官方中文文件寫的是「預設提供盡力而為防護，可選購 600 Gbps 高級清洗」。這兩句不是同一件事。如果你的業務真的可能被打，下單前問清楚你的方案預設拿到的是哪一層。

**4. 流量只計出站。** 單向計費，入站不計。對大部分網站和 API 來說這是好事，但如果你做的是大量下載回源，帳單不會因此變便宜，只是不會被重複計算。

**5. Forge 的成本要看結帳頁。** Forge 除了月費之外還有一筆一次性安裝費，而不同來源對 Forge Mini 的報價出現 $399 與 $599 兩種口徑，落差不算小。實際金額請以結帳頁顯示為準，別拿二手文章裡的數字做預算。

## 誰不該買 GoMami

以下幾種情況，GoMami 不是好選擇：

- **受眾全在歐美**：三網優化的成本你付了，但用不到。
